# Pinakeys V1.0.2

Pinakeys is a portable, offline catalogue of existing materials. Select folders,
leave their files in place, and browse, search and open them through local HTML.
The catalogue also exports CSV, JSON and text.

Manual title and author corrections are stored independently of filenames and
embedded metadata. Quick refresh inventories paths and attributes. Explicit full
verification reads file contents to reconnect records after renames or moves,
detect changed bytes and identify duplicates. Ambiguous copies require a choice;
missing records and unmatched information remain recoverable.

Optional intake provides arrival checks, separate finding categories, metadata
review, proposed filenames and destinations, confirmed filing and undo. Original
document contents are not rewritten. A completed check does not certify safety.

Download `Pinakeys-1.0.2-USB.zip` for the empty kit. The source ZIP is for development.
Compare downloads with `SHA256SUMS`; read `VERIFICATION.md` for exact coverage,
measured conditions and limitations. Extract into a new folder and follow
`QUICKSTART.md`. Keep materials and portable records backed up separately.

Python 3.10+ is required; the desktop app also needs Tkinter. PDF metadata and
security tools are optional and installed separately on each computer. The Mac
bundle is unsigned and not notarized. Windows and Linux remain experimental;
uConsole hardware is unverified. Pinakeys uses the MIT license and retains bundled
third-party notices. The distribution contains no personal materials or catalogues.
